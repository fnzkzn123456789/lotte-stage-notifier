# 롯데시네마 무대인사 알리미

서울·경기·인천 롯데시네마에서 **모든 영화의 무대인사 회차**가 예매 가능한 상태로 확인되면 내 텔레그램으로 알려줍니다.

**PC를 꺼도 무료로 운영하려면 [GitHub Actions 설정 안내](GITHUB_SETUP.md)를 따라 주세요.** 공개 저장소와 표준 Ubuntu 실행기를 사용하며, 5분 간격으로 실행을 예약합니다. GitHub 대기열에 따라 실행이 늦거나 생략될 수 있습니다. 설정이 끝나기 전에는 예약 감시가 꺼져 있습니다.

아래는 필요할 때 PC에서 사용하는 Windows 앱 안내입니다. GitHub 감시와 PC 감시는 알림 기록을 공유하지 않으므로 둘을 동시에 켜면 같은 회차를 각각 알릴 수 있습니다.

## 실행

1. 이 폴더의 **`알리미 실행.cmd`**를 두 번 누릅니다.
2. 텔레그램에서 공식 [@BotFather](https://t.me/BotFather)를 열어 `/newbot`으로 봇을 만듭니다.
3. 발급받은 토큰을 프로그램의 **봇 토큰**에 붙여넣습니다. 토큰은 채팅으로 공유하지 마세요.
4. **방금 만든 봇**의 텔레그램 대화창에서 `/start`를 보냅니다.
5. 프로그램에서 **내 대화 찾기**를 누르고 받을 대화를 선택합니다.
6. **테스트 알림 보내기**로 휴대폰 수신을 확인한 뒤 **감시 시작**을 누릅니다.

토큰 없이 **현재 무대인사 조회**를 눌러 조회 기능부터 사용할 수 있습니다. 이 버튼은 전송 이력이나 감시 기준 상태를 바꾸지 않습니다.

현재 PC의 Codex Python 런타임을 자동으로 찾아 실행합니다. 다른 PC에서는 Tcl/Tk가 포함된 Python 3.10 이상이 필요하며, `python app.py`로도 실행할 수 있습니다. 별도 pip 패키지는 사용하지 않습니다.

## 기본 동작

- 영화관 목록을 공식 사이트에서 읽고 서울 및 경기/인천 지역 전체를 선택합니다. 특정 영화 필터는 없습니다.
- 시사회/무대인사 이벤트 목록을 페이지 끝까지 조회하고, 실제 회차 유형이 무대인사인 것만 선택합니다. 같은 이벤트 양식을 사용하는 GV나 굿즈 상영은 회차 유형이 다르면 제외됩니다.
- 해당 지점·날짜의 전체 상영시간표를 다시 조회해 `IsBookingYN=Y`와 잔여석 `BookingSeatCount>0`을 모두 만족할 때 알립니다.
- 공지 확인 작업이 끝난 뒤 기본 60초를 기다리고 다시 확인합니다. 조회에 걸리는 시간만큼 실제 확인 주기는 더 길어집니다.
- 공지에 없는 회차도 찾기 위해 오늘부터 28일 동안 수도권 전체 시간표를 차례로 조회합니다. 요청 간 최소 0.8초를 두며, 전체 순회에는 **약 30분 이상**이 걸릴 수 있습니다. 공지 없는 회차를 초 단위로 감지하지는 못합니다. 조회 범위는 1~42일로 조정할 수 있습니다. 공지에 있는 회차는 이 일수 제한 없이 확인합니다.
- 처음 확인한 지점·날짜의 **이미 열린 회차**는 기본적으로 기준 상태로 저장합니다. 그 뒤 새로 생기거나 대기/매진에서 예매 가능해진 미통보 회차는 알립니다. 첫 공지 점검 이후 새 공지에 추가된 지점·날짜도 알림 대상입니다.
- 처음부터 현재 예매 가능한 회차도 받고 싶다면 **처음 발견한 이미 예매 가능한 회차도 알림 받기**를 체크한 뒤 첫 감시를 시작하세요. 이미 기준 상태로 저장한 회차를 소급 전송하지는 않습니다.
- 한 번 알림을 보낸 회차는 재시작하거나 좌석이 다시 생겨도 재알림하지 않습니다. 취소표 반복 알림 기능은 아닙니다.
- 예매 링크는 해당 지점의 공식 예매 페이지입니다. 페이지에서 영화와 날짜를 선택해야 합니다.

## 운영과 저장

PC와 프로그램이 켜져 있고 인터넷이 연결되어 있어야 합니다. 종료·절전·재부팅 중에는 확인하지 못하며, 재실행 후 **감시 시작**을 눌러야 합니다. 이 프로그램이 좌석을 예약하거나 결제하지는 않습니다.

`data/credentials.bin`은 Windows DPAPI로 암호화한 토큰·대화 ID입니다. 같은 Windows 계정에서 복호화할 수 있습니다. `data/settings.json`에는 감시 설정, `data/state.sqlite3`에는 관측과 알림 이력이 저장됩니다. `data/` 전체를 공개 저장소에 올리지 마세요.

전송 실패 시 성공 기록을 남기지 않아 다음 조회 때 다시 시도합니다. 텔레그램이 메시지를 받았지만 응답이 유실되는 경우, 또는 전송 직후 앱이 강제 종료되는 경우에는 드물게 중복될 수 있습니다. HTTP 429나 연결 오류에서는 재시도 간격을 늘립니다. 응답 구조가 바뀌면 정상적인 ‘회차 없음’으로 처리하지 않고 오류를 표시합니다.

롯데시네마의 공개 웹사이트 내부 조회 경로를 사용하므로 사이트 개편에 따라 수정이 필요할 수 있습니다. 좌석과 예매 상태는 조회 시점 정보이며 실제 예매 성공을 보장하지 않습니다.

## 개발 및 검증

```powershell
python -m unittest discover -s tests -v
python diagnose.py
python app.py
```

`diagnose.py`는 실제 공개 데이터를 조회해 `data/live-check.json`에 결과를 저장합니다. 텔레그램으로 전송하지 않습니다. 테스트는 실제로 확인한 공개 응답에서 필요한 필드를 추린 fixture와 가상 Telegram 응답을 사용합니다.
